# Плагин ExTrack

Связывает игровой сервер с панелью ExTrack: отправляет логи, защищает вход персонала кодом, выполняет
наказания из панели и передаёт ошибки консоли.

Работает на Paper, Purpur и Folia с 1.16.5 до последних версий, на Java 8 и новее. Один jar на все версии.

**Скачать последнюю версию:** [ExTrack.jar](https://github.com/xlacio/extrack-plugin/releases/latest/download/ExTrack.jar)

Панель: [extrack.su](https://extrack.su)

## Установка

1. Положите `ExTrack.jar` в папку `plugins` и перезапустите сервер.
2. Откройте `plugins/ExTrack/config.yml`, вставьте токен из панели (сервер, Настройки, Подключение).
3. Выполните `/extrack reload`. В консоли появится «Подключено к ExTrack».
4. Привяжите свой игровой аккаунт: в обзоре сервера на сайте получите код и введите `/extrack link <код>`.

## Команды

| Команда | Право | Кто по умолчанию |
| --- | --- | --- |
| `/extrack link <код>` | `extrack.link` | все |
| `/extrack code <код>` | без права | сотрудник при входе |
| `/extrack info <ник>` | `extrack.info` | операторы |
| `/extrack status` | `extrack.status` | операторы |
| `/extrack reload` | `extrack.reload` | операторы |
| `/extrack donation <ник> <сумма[:валюта]> <товар>` | только консоль и RCON | |
| `/report <ник> <текст>` | `extrack.report` | все |
| `/bug <текст>` | `extrack.bug` | все |

`extrack.admin` выдаёт info, status и reload сразу.

## Донат-магазины

Почти все магазины (EasyDonate, TradeMC и другие) после оплаты выполняют команду на сервере. Укажите в
настройках товара команду вида:

```
extrack donation {ник} {сумма} {товар}
```

Плейсхолдеры в фигурных скобках у каждого магазина свои, смотрите его документацию. Валюта по умолчанию
берётся из `donation-currency`, другую можно указать через двоеточие: `extrack donation Notch 5:USD VIP`.

## Для разработчиков плагинов

Добавьте `softdepend: [ExTrack]` в свой plugin.yml и пишите в логи что угодно:

```java
ExTrackApi.log(LogEvent.of(EventType.SHOP)
    .player(player)
    .message("Купил 16 алмазов")
    .data("price", 1200));
```

Вызов дешёвый и безопасный из любого потока, отправка идёт в фоне.

## Нагрузка на сервер

- Слушатели регистрируются только для включённых в `events` типов.
- Игровой поток только кладёт событие в очередь, сеть и JSON работают в отдельных потоках.
- Заморозка персонала слушает движение и урон, только пока кто-то ждёт ввода кода.
- При входе на панель уходит запрос только для сотрудников, обычные игроки заходят без задержки.
- Если панель недоступна, события копятся в памяти (`buffer-size`), а при выключении сервера
  сохраняются в `unsent-events.jsonl` и уходят после запуска.

## Сборка

Каждый релиз собирается GitHub Actions автоматически, jar прикрепляется к релизу. Локально нужна Java 17 или 21:

```
./gradlew build
```

Готовый файл: `build/libs/ExTrack-<версия>.jar`.

## Лицензия

Код открыт, чтобы владельцы серверов могли проверить, что делает плагин. Использовать его можно только вместе
с панелью ExTrack. Копировать, изменять и распространять код или его части без письменного разрешения автора нельзя.
